# 填写对账单

## 两种模式

### 模式A：新建表格
适用于第一次使用、或需要单独创建一个新对账单文件。
- 用户提供空 Excel 文件，或指定一个新的 sheet
- Skill 自动写入表头，然后填充数据

### 模式B：续写表格
适用于已有对账单，追加新单据。**原则上只添加，不删改原有内容。**
- 如需修改已有数据，必须用户文字确权后执行
- 自动查找最后一行，在下方写入新数据

## 输入格式
```json
{
  "mode": "new" | "append",
  "filepath": "/path/to/file.xlsx",
  "sheet": "水电",
  "receipt_no": "0000745",
  "date": "2025-08-16",
  "items": [
    {"name": "密闭套管", "spec": "150×29", "unit": "套", "qty": 2, "price": 76},
    {"name": "", "spec": "150×60", "unit": "套", "qty": 2, "price": 114}
  ]
}
```
name 为空表示与上一行同品种，写入时自动合并单元格。

## 表头格式（固定，不可变）

表头行内容：序号 | 单号 | 日期 | 品种 | 规格 | 单位 | 数量 | 单价 | 金额 | 合计金额

| 属性 | 值 |
|------|-----|
| 字体 | 宋体 |
| 字号 | 11pt |
| 水平对齐 | 居中 |
| 垂直对齐 | 居中 |
| 边框 | 全部细线 |
| 行高 | 自动（内容撑开） |
| 列宽 | 序号40px, 单号90px, 日期90px, 品种100px, 规格120px, 单位50px, 数量60px, 单价70px, 金额90px, 合计100px |

## 数据格式

| 列 | 合并 | 对齐 | 公式 |
|----|------|------|------|
| A 序号 | 跨所有数据行 | 居中 | 无 |
| B 单号 | 跨所有数据行 | 居中 | 无 |
| C 日期 | 跨所有数据行 | 居中 | 无 |
| D 品种 | 同品种合并 | 居中 | 无 |
| E 规格 | 不合并 | 居中 | 无 |
| F 单位 | 不合并 | 居中 | 无 |
| G 数量 | 不合并 | 居中 | 无 |
| H 单价 | 不合并 | 居中 | 无 |
| I 金额 | 不合并 | 居中 | =G×H |
| J 合计 | 跨所有数据行 | 居中 | =SUM(I) |

## 执行步骤

### 模式A：新建
1. 创建/打开 Excel 文件，选择指定 sheet
2. 写入表头（第1行）
3. 从第2行开始写入数据
4. 应用格式

### 模式B：续写
1. 扫描 sheet，找到最后有数据的行
2. 在最后数据行下方隔两行写入新标题和表头
3. 从表头下一行写入数据
4. 应用格式

## 安全规则
- 续写模式：只追加，不修改已有行
- 需要改已有数据时：先告知用户具体改动内容，等用户文字确认后再执行
- 写文件前检查文件是否被 WPS/Excel 打开，如已打开则提醒用户先关闭

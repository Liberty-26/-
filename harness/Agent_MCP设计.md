# MCP: spreadsheet-tools

## 什么是 MCP

**用大白话说：MCP 就是给 AI 配的工具箱。**

Skill 是「大脑」——知道该做什么、按什么顺序做。
MCP 是「手」——具体怎么操作 Excel。

AI 执行 Skill 时，每到一个需要动手的步骤，就调用一个 MCP 工具。MCP 工具完成操作后返回结果，AI 继续下一步。

## 三个工具

### 工具1: find_last_row
**功能**：找到 sheet 中最后一行数据在哪，以及下一个空表头在哪。

**输入**：文件路径、sheet名
**输出**：最后数据行号、建议写入起始行、是否已有空表头

### 工具2: write_batch
**功能**：把一个单据的数据写入 Excel。自动处理合并单元格、公式、格式。

**输入**：文件路径、sheet名、起始行、序号、单号、日期、items 数组（品种/规格/单位/数量/单价）
**输出**：是否成功、写入的行范围、合并了哪些单元格

**内部自动完成**：
- 同品种合并 D 列单元格
- A/B/C/J 列跨所有数据行合并
- I 列写入 =G×H 公式
- J 列写入 =SUM(I) 公式
- 宋体 11pt、居中、细线边框

### 工具3: verify_batch
**功能**：验证刚写入的数据是否正确。

**输入**：文件路径、sheet名、起始行、结束行
**输出**：总行数、合计金额、异常项列表（如有）
